## 2024-05-18 - Added Proper ARIA Attributes to Custom Component Selectors
**Learning:** In highly customized, interactive e-commerce elements like variant selectors that use basic HTML `<button>` tags disguised as pills, it's crucial to specify `aria-pressed={state === id}` rather than leaving screen readers to interpret them simply as generic buttons. This pattern recurs in custom toggle components and is necessary for users dependent on assistive technology to know which option is actively selected. Similarly, any icon-only button like a modal `X` close must have `aria-label="Close"` and a strong focus state for keyboard navigation.
**Action:** When creating or reviewing custom toggle UI elements built with generic buttons instead of standard radio/checkbox inputs, always ensure that `aria-pressed` or `aria-expanded` attributes reflect their active state, and ensure all icon-only buttons receive `aria-label`s and visible keyboard focus states (`focus-visible:ring-2` etc).
