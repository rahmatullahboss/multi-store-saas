## 2024-06-28 - Accessible Accordion/FAQ Patterns
**Learning:** In reusable template components like FAQs, interactive accordion sections often miss critical ARIA attributes out-of-the-box, breaking accessibility for screen reader users. Specifically, missing `aria-expanded` prevents users from knowing if the answer is visible, missing `aria-controls` prevents relationship building, and missing `type="button"` on the toggle triggers default form behaviors if placed within forms. Furthermore, keyboard users require distinct focus indicators (like `focus-visible:ring-2`) to navigate easily.
**Action:** When building interactive disclosures or accordions, strictly pair the trigger button with `aria-expanded={isOpen}`, `aria-controls="answer-id"`, and `type="button"`. Apply `role="region"` and `aria-labelledby="button-id"` to the content panel. Always include explicit `focus-visible` styles for keyboard navigation.
