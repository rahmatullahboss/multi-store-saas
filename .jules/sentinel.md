## 2025-04-10 - [XSS] Missing HTML Sanitization in Product Descriptions
**Vulnerability:** Raw HTML injection (Cross-Site Scripting) via `dangerouslySetInnerHTML` when rendering the `product.description` field in the DC Store theme template (`ProductPage.tsx`).
**Learning:** Store themes and templates that parse rich text often skip calling validation/sanitization utilities (like `sanitizeHtml`) to preserve formatting, thereby opening attack vectors if the user-generated input (e.g. `product.description`) has been manipulated to include malicious script tags.
**Prevention:** Always verify that newly ported or constructed components wrap untrusted/user-supplied text (such as product descriptions, user bios, review contents) with `sanitizeHtml()` from `~/utils/sanitize` before passing it to React's `dangerouslySetInnerHTML`.
