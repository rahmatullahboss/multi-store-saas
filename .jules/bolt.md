## 2024-05-24 - Optimize N+1 queries in Cloudflare D1/SQLite
**Learning:** Cloudflare D1/SQLite lacks support for complex joined aggregates without explicit subqueries, leading to common N+1 latency problems. However, `Promise.all` mapping over rows crashes local `better-sqlite3` tests. Drizzle's `db.batch()` is D1-specific and also crashes locally.
**Action:** The safest and most performant cross-environment optimization for N+1 aggregates is combining `inArray()` with `GROUP BY` and an aggregate function (e.g., `max()`), followed by manually mapping the array results into O(1) lookups using JS Maps before applying them back to the original source object array.
